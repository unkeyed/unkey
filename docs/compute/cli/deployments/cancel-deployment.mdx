Cancel a deployment that has not finished yet: queued, waiting for
approval, building, or deploying. Cancelling aborts its run and marks it
`cancelled`.

Only in-progress deployments can be cancelled. To take a `ready` preview
deployment offline, use [deployments stop](/compute/cli/deployments/stop-deployment) instead.

Cancellation is asynchronous: this endpoint only enqueues it and returns
immediately. Poll [deployments get](/compute/cli/deployments/get-deployment) until the status reaches `cancelled`.

## Usage

```bash
unkey deployments cancel --deployment-id=<deployment-id> [flags]
```

## Flags

<ParamField body="--deployment-id" type="string" required>
  Identifies the deployment by its unique ID or slug. Accepts a prefixed deployment ID such as `d_1234abcd` or a slug.
</ParamField>

## Required permissions

Your root key must have the following permission:

- `unkey:v1:<workspace_id>:projects/<project_id>/apps/<app_id>/environments/<environment_id>/deployments/<deployment_id>#write`

See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash
unkey deployments cancel --deployment-id=d_1234abcd
```

Send the request body as JSON:

```bash
unkey deployments cancel --body='{"deploymentId":"d_1234abcd"}'
```

## API endpoint

The command calls `POST /v2/deployments.cancelDeployment` and prints its response. See the <a href="https://github.com/unkeyed/unkey/blob/main/svc/api/openapi/spec/paths/v2/deployments/cancelDeployment/index.yaml" target="_blank">endpoint definition</a> for the HTTP contract. Request fields use camelCase in `--body`.
