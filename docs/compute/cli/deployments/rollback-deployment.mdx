Move live traffic back to an earlier deployment of an <Tooltip tip="A Compute app: a deployable service inside a project. Not your application in general.">app</Tooltip>. `--deployment-id` is the deployment you want to go back to.

The target must be `ready`, in the production <Tooltip tip="A production or preview environment of a Compute app, not the dashboard label on a key.">environment</Tooltip>, not shutting down, and not already current. After a rollback, new deployments stop taking over live traffic automatically until you promote the rolled-back deployment or a newer one. The command returns right away. Poll `unkey deployments get` or `unkey deployments list` for the result.

Rolling back needs an active Compute plan. Without one the API answers 412 with `The workspace has no active Compute plan.` A workspace over its Compute spend cap gets `The workspace is suspended by its Compute spend cap. Raise the spend limit to resume.` See [Compute plans](/compute/get-started/plans).

## Usage

```bash
unkey deployments rollback --deployment-id=<deployment id>
```

## Required permissions

Your root key needs write on the environment:

- `unkey:v1:<workspace_id>:projects/<project_id>/apps/<app_id>/environments/<environment_id>#write`

If the deployment doesn't exist or your key doesn't have the permission, you get the same 404: `The requested deployment does not exist.` If your key can read the deployment, you get a 403 that names the missing permission instead. See [Root key permissions](/platform/root-keys/permissions) for the full catalog.

## Examples

Roll back to a known good deployment:

```bash
unkey deployments rollback --deployment-id=d_1234abcd
```

Send the request body as JSON:

```bash
unkey deployments rollback --body='{"deploymentId":"d_1234abcd"}'
```

## API endpoint

The command calls [`POST /v2/deployments.rollbackDeployment`](/compute/api-reference/deployments/rollback-deployment) and prints its response. The request fields carry the same names as the flags in camelCase, which is the shape `--body` expects.
