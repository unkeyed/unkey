List the <Tooltip tip="Groups of apps, usually one per codebase or product.">projects</Tooltip> in your workspace. Results are ordered by project ID and paginated. When `pagination.hasMore` is true, pass `pagination.cursor` back with `--cursor`.

## Usage

```bash
unkey projects list [--limit=<n>] [--cursor=<cursor>] [--search=<text>]
```

## Flags

<ParamField body="--cursor" type="string">
  Pagination cursor from a previous response.
</ParamField>

<ParamField body="--limit" type="integer" default="100">
  Maximum number of projects per page, between 1 and 100.
</ParamField>

<ParamField body="--search" type="string">
  Free-form text, at most 256 characters. Returns projects whose ID, name, or slug contains it, matched case-insensitively.
</ParamField>

## Required permissions

Your root key needs `project.*.read_project`.

Without a matching permission the API answers 403 and the CLI prints `Permission denied:` followed by the detail. See [Root key permissions](/platform/root-keys/permissions) for the full catalog.

## Examples

List every project:

```bash
unkey projects list
```

Filter and page:

```bash
unkey projects list --limit=25 --search=billing
```

Send the request body as JSON:

```bash
unkey projects list --body='{"limit":25}' --output=json
```

## API endpoint

The command calls [`POST /v2/projects.listProjects`](/compute/api-reference/projects/list-projects) and prints its response. The request fields carry the same names as the flags in camelCase, which is the shape `--body` expects.
