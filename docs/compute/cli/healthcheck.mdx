Send one HTTP GET request to a URL and exit 0 if the server answers 200, or exit 1 otherwise. The command needs no root key and probes the URL you pass. Use it as a small probe for CI pipelines, load balancer checks, and monitoring scripts, for example against the hostname of a deployment.

## Usage

```bash
unkey healthcheck <url>
```

Exactly one URL is required. Missing or extra arguments exit 1 with `usage: unkey healthcheck <url>`. The command has no flags.

## Behavior

Redirects are followed and there's no request timeout, so a server that never answers keeps the command waiting. A 200 response prints `Healthy: HTTP 200 from <url>` to stdout and exits 0. Any other status exits 1 with `healthcheck failed: HTTP <code> from <url>`. A connection error exits 1 with `healthcheck failed:` followed by the underlying error. Errors go to stderr. Use the exit status, not the success text, to gate a script.

## Examples

Probe a deployment hostname:

```bash
unkey healthcheck https://payments-payments-api-production-acme.unkey.app/health
```

Alert when a service is down:

```bash
unkey healthcheck https://example.com/api/status || echo 'Service is down!'
```

Gate a pipeline step:

```bash
unkey healthcheck http://localhost:8080/health && npm test
```
