Start installing the Unkey GitHub App for your workspace. The command returns a GitHub install URL. Open it in a browser, install the app, and choose which repositories it can see. GitHub then sends you back to your workspace settings in Unkey.

The URL expires 15 minutes after the call (`expiresAt`, in Unix milliseconds). Run the command again for a new one. Once installed, connect repositories to individual <Tooltip tip="Compute apps: deployable services inside a project. Not your applications in general.">apps</Tooltip> with the `--git` flag of [apps create](/compute/cli/apps/create-app) and [apps update](/compute/cli/apps/update-app).

## Usage

```bash
unkey github install
```

## Required permissions

Your root key needs `workspace.*.install_github`.

Without a matching permission the API answers 403 and the CLI prints `Permission denied:` followed by the detail. See [Root key permissions](/platform/root-keys/permissions) for the full catalog.

## Examples

Get the install URL:

```bash
unkey github install
```

Print only the URL:

```bash
unkey github install --output=json | jq -r '.data.url'
```

## API endpoint

The command calls [`POST /v2/github.installApp`](/compute/api-reference/github/install-github-app) and prints its response. The endpoint takes no request fields.
