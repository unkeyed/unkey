You need a Compute plan to deploy. Compute is billed separately from API Management, so a paid API plan doesn't include Compute, and you can buy Compute while on the free API tier. For billing and cancellation across both products, see [Plans](/platform/billing/plans).

## When the plan is checked

Unkey checks for a Compute plan whenever you:

- Create a <Tooltip tip="A group of apps, usually one per codebase or product.">project</Tooltip> or a <Tooltip tip="One built and running version of an app in one environment.">deployment</Tooltip>.
- Promote or roll back a deployment.
- Approve a fork deployment.
- Push to a connected GitHub repository.

## Plans and their limits

Each plan sets the limits for your workspace. The dashboard shows the same numbers on [Limits](/platform/billing/limits), and [Compute limits](/compute/configure/limits) covers where each one is enforced.

| Limit | Starter | Pro | Business |
| --- | --- | --- | --- |
| CPU per instance | 2 vCPU | 8 vCPU | 16 vCPU |
| Memory per instance | 2 GiB | 8 GiB | 32 GiB |
| Ephemeral disk per instance | 10 GiB | 10 GiB | 10 GiB |
| Workspace CPU across running instances | 30 vCPU | 120 vCPU | 240 vCPU |
| Workspace memory across running instances | 60 GiB | 240 GiB | 480 GiB |
| Workspace ephemeral disk across running instances | 120 GiB | 480 GiB | 960 GiB |
| Replicas per region for one app | 4 | 8 | 16 |
| Concurrent builds | 1 | 1 | 1 |
| Custom domains | 1 | Unlimited | Unlimited |
| Log query range | 3 days | 7 days | 14 days |
| Team members | No | Yes | Yes |

## Spend budget

Usage above what your plan includes is metered. Workspace admins can set a monthly spend budget under **Settings > Billing**, and Unkey emails them at 50, 75, and 100 percent of it. If you turn on **Stop workloads at the budget**, reaching 100 percent stops every deployment in the workspace until you raise the budget, remove it, or turn the option off. See [Spend budget](/compute/configure/spend-budget).

## Canceling or downgrading

Canceling Compute takes effect immediately:

- Running deployments are torn down permanently.
- The current period isn't refunded.
- You can't deploy, promote, or roll back until you pick a plan again.

If the workspace is on the free API Management tier, canceling Pro or Business, or downgrading to Starter, deactivates every team member except the workspace creator.
