# Illustration brand marks

These marks identify integrations, not endorsements. Keep their original geometry and proportions. Full-color marks retain their source colors; monochrome marks use a light or dark treatment for contrast.

| Mark | Source |
| --- | --- |
| GitHub | [Official brand toolkit](https://brand.github.com/foundations/logo), `GitHub_Logos.zip`, `GitHub_Invertocat_Black.svg` |
| Unkey, Docker, TypeScript, Go, Python | Existing `web/internal/icons/src/icons/` assets |
| Hono | [Official logo](https://hono.dev/images/logo.svg) |
| Bun | [Official logo](https://bun.sh/logo.svg) |

The artwork generator embeds these local vectors, so card rendering does not depend on third-party requests. Cloudflare uses the standalone cloud symbol paths from its horizontal logo. Source files are retained here to make provenance and future brand updates reviewable.
