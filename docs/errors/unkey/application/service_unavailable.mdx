<Danger>`err:unkey:application:service_unavailable`</Danger>

The API failed on our side and couldn't finish your request. You get HTTP 500, and `detail` names what failed. Unless `detail` says otherwise, the request didn't take effect.

```json Example response
{
  "meta": {
    "requestId": "req_2c9a0jf23l4k567"
  },
  "error": {
    "detail": "Failed to create deployment.",
    "status": 500,
    "title": "Internal Server Error",
    "type": "/errors/unkey/application/service_unavailable"
  }
}
```

## How to fix

1. Retry with exponential backoff, and check the Unkey status page for an incident.
2. If it keeps failing, contact support with the `requestId`.

Two cases need something else:

- **HTTP 503 on `domains.listDomains`.** Your filters match too many domains. The `detail` is `The domain scan limit was reached. Narrow the project, app, environment, or search filters and retry.` Narrow the filters.
- **`Resource limits are not configured for this workspace.`** Your workspace is missing its plan limits. Retrying won't help, so contact support.
