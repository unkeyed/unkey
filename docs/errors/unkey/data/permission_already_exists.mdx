<Danger>`err:unkey:data:permission_already_exists`</Danger>

A permission with the same slug already exists in your workspace, so `permissions.createPermission` didn't create one. You get HTTP 409.

```json Example response
{
  "meta": {
    "requestId": "req_2c9a0jf23l4k567"
  },
  "error": {
    "detail": "A permission with slug 'documents.read' already exists in this workspace",
    "status": 409,
    "title": "Conflicting Resource",
    "type": "/errors/unkey/data/permission_already_exists"
  }
}
```

## Likely causes

- You already created this permission. Slugs are unique per workspace.

## How to fix

1. Reuse the existing permission (find it with `permissions.listPermissions`), or pick a different slug.

In provisioning code, treat a 409 as success and continue.

## Related errors
