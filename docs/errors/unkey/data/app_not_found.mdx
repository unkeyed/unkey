<Danger>`err:unkey:data:app_not_found`</Danger>

The <Tooltip tip="A Compute app: a deployable service inside a project, not an application in the API Management sense.">app</Tooltip> you referenced doesn't exist in the project. You get HTTP 404.

```json Example response
{
  "meta": {
    "requestId": "req_2c9a0jf23l4k567"
  },
  "error": {
    "detail": "The requested app does not exist.",
    "status": 404,
    "title": "Not Found",
    "type": "/errors/unkey/data/app_not_found"
  }
}
```

## Likely causes

- The app ID or slug has a typo.
- You passed the wrong project, so the app isn't in it.
- Your root key doesn't have read permission on the app. `apps.getApp` returns this 404 instead of a 403.

## How to fix

1. List the project's apps with `apps.listApps` and use the returned ID or slug.
2. Make sure the project you pass is the one that owns the app.
3. Check that the root key has read (or the relevant write) permission on the app.
