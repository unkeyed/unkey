---
title: "connection_conflict"
description: "The connection duplicates an existing default in the caller environment."
---

<Danger>`err:unkey:data:connection_conflict`</Danger>

The connection request returns HTTP 409 without changing connection defaults.

- If the target app is already connected in this environment, edit the existing connection.
- If the name is already in use, choose another name.

Existing deployments keep their saved connections.
