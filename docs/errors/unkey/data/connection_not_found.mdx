---
title: "connection_not_found"
description: "The connection does not exist or is not readable by this credential."
---

<Danger>`err:unkey:data:connection_not_found`</Danger>

The connection request returns HTTP 404. Check the connection ID and workspace,
and grant the credential read access to the caller environment.

Deleted connection defaults cannot be edited. Existing deployments can still
retain a saved connection with the same ID.
