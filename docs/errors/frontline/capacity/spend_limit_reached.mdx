<Danger>`err:frontline:capacity:spend_limit_reached`</Danger>

import { ProductLink } from "/snippets/product-link.jsx";

The workspace that owns this API reached its monthly Compute spend budget, so its compute is paused. Nothing is broken and no data is lost. You get `402 Payment Required`.

```json Example response
{
  "meta": {
    "requestId": "req_3k2j1h0g9f8e7d6c"
  },
  "error": {
    "code": "err:frontline:capacity:spend_limit_reached",
    "message": "Compute for this workspace is paused because it reached its spend limit. Raise or remove the spend budget to resume."
  }
}
```

Browsers get the same error as an HTML page.

## If you're calling an API hosted on Unkey

You can't fix this, and retrying returns the same 402. The API owner has to raise or remove their spend budget, or wait for the next billing month. Tell them you're seeing this error, in case they missed our email.

## If you own this API

You set a monthly Compute budget with **Stop workloads at the budget** turned on, and this month's spend reached it. We email workspace admins at 50, 75, and 100 percent of the budget. Spend is measured before credits are subtracted.

While compute is paused, your deployments are torn down and every request gets this 402. You also can't start, promote, roll back, or wake a deployment, and pushes to GitHub don't deploy.

### How to fix

1. Open **Settings > Billing** in the dashboard.
2. Raise the **Monthly budget** above your current spend, remove the budget, or turn off **Stop workloads at the budget**.
3. Allow a few minutes. Removing the budget or turning off the stop resumes compute on the next check. Raising the budget resumes it once two checks in a row see spend under the new budget.

A new billing month resets month-to-date spend, and a paused workspace resumes the same way.
