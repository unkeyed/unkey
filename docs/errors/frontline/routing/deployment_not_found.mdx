<Danger>`err:frontline:routing:deployment_not_found`</Danger>

This code is reserved, and the gateway doesn't return it. A hostname that doesn't point at a deployment returns [`err:frontline:routing:config_not_found`](/errors/frontline/routing/config_not_found) instead.

## How to fix

There's nothing to fix. If a hostname won't route, start from [`err:frontline:routing:config_not_found`](/errors/frontline/routing/config_not_found).

## Related errors

- [`err:frontline:routing:config_not_found`](/errors/frontline/routing/config_not_found): the hostname has no route, which is the routing error you actually see.
- [`err:unkey:data:deployment_not_found`](/errors/unkey/data/deployment_not_found): a different error, from the Unkey API, for a deployment ID that doesn't exist.
