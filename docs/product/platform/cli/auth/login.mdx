`unkey auth login` is `unkey login`. It starts a device login, or stores a root key you pass with `--root-key`.

## Usage

```bash
unkey auth login
```

The flags match [unkey login](/platform/cli/login): `--api-url`, `--no-browser`, and `--root-key`. On success the key is saved to the system keychain (or to `~/.unkey/config.toml` when the keychain is unavailable) and is not printed.

See [CLI authentication](/platform/cli/authentication) for which key `unkey api` uses. `unkey deploy` ignores the stored key.
