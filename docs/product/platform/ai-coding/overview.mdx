You can connect an AI coding assistant like Claude Code, Cursor, or VS Code to Unkey in two ways. It can act on your workspace through Unkey's MCP servers, and it can read these docs while it writes code for you.

## Let your assistant act on Unkey

Unkey hosts two MCP servers. Add one to your assistant with a root key, and it can call the Unkey API for you.

- **Unkey**: every v2 API endpoint, so keys, keyspaces, identities, permissions, rate limits, analytics, portals, and Compute.
- **Compute**: only the Compute endpoints, for projects, apps, environments, deployments, domains, and gateway policies.

See [Unkey MCP servers](/platform/ai-coding/mcp-servers) for the URLs, the root key to use, and example prompts.

## Give your assistant the docs

- **Docs MCP server**: lets your assistant search these docs while it works. Its URL is below. You can also add it from the menu next to **Copy page** at the top of any page, which has **Connect to Cursor**, **Connect to VS Code**, **Copy MCP Server**, and **Copy MCP install command**.
- **Markdown**: **Copy page** copies the page as Markdown you can paste into a chat. Add `.md` to the end of any docs URL to get the same thing as plain text.
- **llms.txt**: an index of every page, built for language models. `llms-full.txt` has the full text of the docs in one file.

```text
https://www.unkey.com/docs/mcp
https://www.unkey.com/docs/llms.txt
https://www.unkey.com/docs/llms-full.txt
```

## Use the CLI

Assistants that run terminal commands can also use the `unkey` CLI. Pass `--output=json` so they get the full API response. See [Install the CLI](/platform/cli/install).
