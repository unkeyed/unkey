A platform feature is an Unkey capability that you can enable or disable for
your workspace. Unkey sets the default for each feature. Workspace admins can
choose a different setting when Unkey permits self-service changes.

Platform features apply to everyone in the workspace, not to an individual
member, project, or environment. Available features appear under
**Settings > Platform features**.

## Enable or disable a feature

You must be a workspace admin to change platform features. Other members can
view the settings, but their controls are disabled.

1. Navigate to **Settings > Platform features**.
2. Find the feature and read its description.
3. Turn its switch on to enable it, or off to disable it.

Changes save automatically. The switch is disabled while a change is saving.
Turning a feature off saves a disabled setting for this workspace.

If the feature is managed by Unkey, its switch stays disabled.

## Handle errors

If platform features fail to load, click **Retry**. If a save fails, the page
restores the switch to its last saved state and shows an error beside that
feature. Try the switch again to retry the change.
After reloading the page, a recent change can take time to appear while database
replicas catch up.

If the page shows **No platform features available**, Unkey has not made any
features available to configure. You don't need to create a feature.
