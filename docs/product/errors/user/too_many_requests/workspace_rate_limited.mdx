<Danger>`err:user:too_many_requests:workspace_rate_limited`</Danger>

Your workspace is sending too many requests to the Unkey API, so this request was refused. Nothing ran, so it's safe to retry. You get HTTP 429.

```json Example response
{
  "meta": {
    "requestId": "req_2c9a0jf23l4k567"
  },
  "error": {
    "detail": "This workspace has exceeded its API rate limit of 600/1m0s. Please try again later.",
    "status": 429,
    "title": "Too Many Requests",
    "type": "/errors/user/too_many_requests/workspace_rate_limited"
  }
}
```

## How to fix

1. Wait a moment, then retry with exponential backoff.
2. If it keeps happening, contact [support@unkey.com](mailto:support@unkey.com).
