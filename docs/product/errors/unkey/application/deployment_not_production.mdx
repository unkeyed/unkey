<Danger>`err:unkey:application:deployment_not_production`</Danger>

You asked to promote or roll back to a preview deployment. Only a deployment in a production <Tooltip tip="A production or preview environment of a Compute app, not the dashboard label on a key.">environment</Tooltip> can become the one serving your production hostname. You get HTTP 412.

```json Example response
{
  "meta": {
    "requestId": "req_2c9a0jf23l4k567"
  },
  "error": {
    "detail": "Only production deployments can be promoted or rolled back.",
    "status": 412,
    "title": "Precondition Failed",
    "type": "/errors/unkey/application/deployment_not_production"
  }
}
```

## Likely causes

- The deployment ID is from a preview environment. Preview deployments have their own URLs and never serve the production hostname.

## How to fix

1. Deploy the same commit or image to the production environment with `deployments.createDeployment`.
2. Promote that deployment.

To test a preview deployment, use its own URL. See [Production and preview](/compute/concepts/production-and-preview) for how the two differ.
