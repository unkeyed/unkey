<Danger>`err:unkey:application:assertion_failed`</Danger>

Something went wrong on our side. It's a bug in Unkey, not a problem with your request. You get HTTP 500 with an empty `detail`.

```json Example response
{
  "meta": {
    "requestId": "req_2c9a0jf23l4k567"
  },
  "error": {
    "detail": "",
    "status": 500,
    "title": "Internal Server Error",
    "type": "/errors/unkey/application/assertion_failed"
  }
}
```

## How to fix

1. Retry once, with backoff, if the request is safe to repeat.
2. If it fails again, contact support with the `requestId`, the endpoint, and the time. We need the `requestId` to find what failed.

## Related errors

- [`err:unkey:application:unexpected_error`](/errors/unkey/application/unexpected_error): another failure on our side with no more specific code.
