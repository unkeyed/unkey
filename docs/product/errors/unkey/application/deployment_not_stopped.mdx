<Danger>`err:unkey:application:deployment_not_stopped`</Danger>

You asked to start a deployment that isn't stopped. You get HTTP 412.

```json Example response
{
  "meta": {
    "requestId": "req_2c9a0jf23l4k567"
  },
  "error": {
    "detail": "The deployment is not stopped.",
    "status": 412,
    "title": "Precondition Failed",
    "type": "/errors/unkey/application/deployment_not_stopped"
  }
}
```

## Likely causes

- The deployment is already running.
- The deployment is still building.
- The deployment failed.

A deployment that's still shutting down after a stop counts as stopped, so you can start it right away.

## How to fix

1. Read the deployment with `deployments.getDeployment`. `start` is in its `availableActions` only when the call would succeed.
2. If it's already running, there's nothing to do.
3. If it never became ready, create a new deployment instead.

## Related errors

- [`err:unkey:application:deployment_is_production`](/errors/unkey/application/deployment_is_production): production deployments can't be started directly.
- [`err:unkey:application:deployment_not_running`](/errors/unkey/application/deployment_not_running): the mirror case on stop.
- [`err:unkey:application:precondition_failed`](/errors/unkey/application/precondition_failed): the workspace is paused at its spend limit, which also blocks start.
