<Danger>`err:unkey:application:deployment_is_production`</Danger>

You tried to stop or start a production deployment, and you can't do that directly. You get HTTP 412.

```json Example response
{
  "meta": {
    "requestId": "req_2c9a0jf23l4k567"
  },
  "error": {
    "detail": "Production deployments cannot be stopped.",
    "status": 412,
    "title": "Precondition Failed",
    "type": "/errors/unkey/application/deployment_is_production"
  }
}
```

## Likely causes

- You called `deployments.stopDeployment` or `deployments.startDeployment` on a production deployment. Stop and start are only for preview deployments.

## How to fix

1. To take a production deployment out of service, promote or roll back to another production deployment with `deployments.promoteDeployment` or `deployments.rollbackDeployment`.
2. Use stop and start only on preview deployments.

See [Production and preview](/compute/concepts/production-and-preview) for what each kind of environment allows.

## Related errors

- [`err:unkey:application:deployment_not_production`](/errors/unkey/application/deployment_not_production): the opposite case: promote and rollback need a production deployment.
- [`err:unkey:application:deployment_not_running`](/errors/unkey/application/deployment_not_running): stop was called on a deployment that isn't running.
