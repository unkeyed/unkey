<Danger>`err:unkey:data:analytics_connection_failed`</Danger>

Your analytics query couldn't run because of a failure on our side. Nothing about the query caused it. You get HTTP 503.

```json Example response
{
  "meta": {
    "requestId": "req_2c9a0jf23l4k567"
  },
  "error": {
    "detail": "Failed to connect to ClickHouse analytics database",
    "status": 503,
    "title": "Service Unavailable",
    "type": "/errors/unkey/data/analytics_connection_failed"
  }
}
```

## How to fix

1. Retry with exponential backoff. It usually clears quickly.
2. Check the Unkey status page for an incident.
3. If it keeps failing, contact support with the `requestId`.

## Related errors

- [`err:unkey:data:analytics_not_configured`](/errors/unkey/data/analytics_not_configured): analytics isn't enabled for your workspace.
- [`err:unkey:application:service_unavailable`](/errors/unkey/application/service_unavailable): other failures on our side, reported as 500.
- [`err:user:unprocessable_entity:query_execution_timeout`](/errors/user/unprocessable_entity/query_execution_timeout): the query ran but timed out.
