Compute takes a GitHub repository or a container image and turns it into a running <Tooltip tip="A Compute app: a deployable service inside a project. Not 'your application' in general.">app</Tooltip>. You get a production and a preview <Tooltip tip="A production or preview environment of a Compute app, not the dashboard label on a key.">environment</Tooltip>, automatic domains, promote and rollback, and a gateway in front of every <Tooltip tip="One built and running version of an app in one environment.">deployment</Tooltip>.
