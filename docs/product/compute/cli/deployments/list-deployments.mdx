List deployments in the workspace, newest first. All filters are optional. With none set, every deployment in the workspace is returned. Filters nest: `--app` requires `--project`, and `--environment` requires both. When `pagination.hasMore` is true, pass `pagination.cursor` back with `--cursor`.

`--status` takes a comma-separated list of statuses from `pending`, `starting`, `building`, `deploying`, `network`, `finalizing`, `ready`, `failed`, `skipped`, `awaiting_approval`, `stopped`, `superseded`, and `cancelled`.

## Usage

```bash
unkey api deployments list-deployments [--project=<project> [--app=<app> [--environment=<environment>]]] [--status=<status>,...] [--limit=<n>] [--cursor=<cursor>]
```

## Flags

<ParamField body="--app" type="string">
  App ID or slug to filter by. Requires `--project`.
</ParamField>

<ParamField body="--cursor" type="string">
  Pagination cursor from a previous response.
</ParamField>

<ParamField body="--environment" type="string">
  Environment ID or slug to filter by. Requires `--project` and `--app`.
</ParamField>

<ParamField body="--limit" type="integer">
  Maximum deployments per page, between 1 and 100. The API uses 100 when the flag is omitted.
</ParamField>

<ParamField body="--project" type="string">
  Project ID or slug to filter by.
</ParamField>

<ParamField body="--status" type="string[]">
  Comma-separated lifecycle statuses to include.
</ParamField>

## Required permissions

Your root key needs `environment.*.read_deployment`.

A grant for a single environment isn't enough, because the list spans environments.

Without a matching permission the API answers 403 and the CLI prints `Permission denied:` followed by the detail. See [Root key permissions](/platform/root-keys/permissions) for the full catalog.

## Examples

Deployments of one environment:

```bash
unkey api deployments list-deployments --project=payments --app=payments-api --environment=production
```

Recent successes and failures across the workspace:

```bash
unkey api deployments list-deployments --status=ready,failed --limit=25
```

## API endpoint

The command calls [`POST /v2/deployments.listDeployments`](/compute/api-reference/deployments/list-deployments) and prints its response. The request fields carry the same names as the flags in camelCase, which is the shape `--body` expects.
