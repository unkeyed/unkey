List the variables of an <Tooltip tip="A production or preview environment of a Compute app, not the dashboard label on a key.">environment</Tooltip>. Results are ordered by variable ID and paginated. When `pagination.hasMore` is true, pass `pagination.cursor` back with `--cursor`.

`recoverable` variables include their value. `writeonly` variables never do: their `value` is an empty string.

## Usage

```bash
unkey api environments list-environment-variables --project=<project> --app=<app> --environment=<environment> [--limit=<n>] [--cursor=<cursor>]
```

## Flags

<ParamField body="--app" type="string" required>
  App ID or slug.
</ParamField>

<ParamField body="--cursor" type="string">
  Pagination cursor from a previous response.
</ParamField>

<ParamField body="--environment" type="string" required>
  Environment ID or slug.
</ParamField>

<ParamField body="--limit" type="integer">
  Maximum variables per page, between 1 and 100. The API uses 100 when the flag is omitted.
</ParamField>

<ParamField body="--project" type="string" required>
  Project ID or slug. Both forms resolve to the same project.
</ParamField>

## Required permissions

Your root key needs one of:

- `environment.*.read_environment_variables` (any environment)
- `environment.<environment_id>.read_environment_variables` (a specific environment)

Without a matching permission the API answers 403 and the CLI prints `Permission denied:` followed by the detail. See [Root key permissions](/platform/root-keys/permissions) for the full catalog.

## Examples

List the variables of production:

```bash
unkey api environments list-environment-variables --project=payments --app=payments-api --environment=production
```

Smaller pages:

```bash
unkey api environments list-environment-variables --project=payments --app=payments-api --environment=production --limit=25
```

## API endpoint

The command calls [`POST /v2/environments.listEnvironmentVariables`](/compute/api-reference/environments/list-environment-variables) and prints its response. The request fields carry the same names as the flags in camelCase, which is the shape `--body` expects.
