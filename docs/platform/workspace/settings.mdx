**Settings > General** holds the three workspace-wide settings: the name, the workspace ID, and the GitHub App connection.

## General

<Frame>
  <img src="/images/dashboard/platform--workspace-settings--general.png" alt="General settings page showing the workspace name, the workspace ID with a copy button, and the GitHub App card marked Connected" />
</Frame>

<ParamField path="Workspace name" type="string" required>
  Between 3 and 50 characters. Internal only: your users never see it. Only an admin can save a new name. Other roles see the field, but **Save** stays disabled with "Admin access required to rename the workspace". Renaming writes a `workspace.update` audit log entry.
</ParamField>

<ParamField path="Workspace ID" type="string">
  Read-only. The `ws_` identifier with a copy button. Use it in API calls and support requests. The slug in the URL is a different identifier and can't be changed. See [Workspaces](/platform/workspace/overview).
</ParamField>

<ParamField path="GitHub" type="connection">
  Whether the Unkey GitHub App is installed for this workspace. **Install GitHub App** sends you to GitHub to pick the repos Unkey may read. Once it's installed, the card shows **Connected** and the button becomes **Manage on GitHub**. That connection is what lets Compute deploy an <Tooltip tip="A Compute app: a deployable service inside a project. Not 'your application' in general.">app</Tooltip> from a repo and create preview <Tooltip tip="A production or preview environment of a Compute app, not the dashboard label on a key.">environments</Tooltip> per pull request. API Management-only workspaces can leave it disconnected.
</ParamField>
