When TruffleHog finds a working Unkey [root key](/platform/root-keys/overview) in a public source, it tells us. Unkey deletes the key right away and emails everyone in the workspace that owns it.

TruffleHog looks for Unkey root keys in public sources such as GitHub, GitLab, Docker images, npm, PyPI, and Hugging Face. Don't rely on this detection for the API keys you issue with your own prefixes. [GitHub secret scanning](/platform/security/github-secret-scanning) sends an email but never deletes the key.

## What happens

<Steps titleSize="h3">
  <Step title="TruffleHog finds the key">
    TruffleHog spots an Unkey root key in a public source, confirms that the key works, and reports it to us with the URL where it was found.
  </Step>
  <Step title="Unkey checks the reported key">
    Unkey verifies TruffleHog's signature and looks up the reported key's hash. If the key or its workspace has been deleted, or no key matches, nothing happens.
  </Step>
  <Step title="Unkey deletes the key">
    Unkey deletes the key, as if you had deleted it yourself. This includes keys that are disabled or expired, because those can be turned back on. The [audit log](/platform/workspace/audit-logs/overview) records the deletion with the `system` actor. Requests with the key can still succeed for up to about 30 seconds after the deletion.
  </Step>
  <Step title="Your team gets an email">
    Every member of the workspace gets an email saying the key was deleted. It names the source and the URL where the key was found. Repeated copies of a key within one report produce one email per member.
  </Step>
</Steps>

## What you should do

Any service that still uses the deleted key gets errors until you give it a new one.

1. Under **Root Keys** in the dashboard sidebar, create a replacement key with the same permissions.
2. Update the services that used the old key. If the key is stored as a Compute environment variable, [find every app that sets it](/compute/configure/environment-variables#find-a-variable-across-the-workspace).
3. Remove the secret from the place where it was published.
