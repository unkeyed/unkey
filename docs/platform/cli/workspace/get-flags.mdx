Get feature flags for the workspace associated with your credentials.

Each flag is keyed by its slug and includes its current value, description,
and whether it can be enabled or disabled. A workspace-specific value takes
precedence over the flag's default. If no flags are available, `data` is an
empty object.

This command takes no request-building flags and does not accept `--body`.

## Usage

```bash
unkey workspace flags get [flags]
```

## Flags

This command accepts only the shared flags below.

### Shared flags

These flags control authentication, requests, and output. [CLI output and shared flags](/platform/cli/output-and-flags) describes them in full.

<ParamField body="--root-key" type="string">

  Base URL of the API. Falls back to `UNKEY_API_BASE_URL`. You don't normally need to set it.

</ParamField>

## Required permissions

Your root key must have the following permission:

- `unkey:v1:<workspace_id>:flags#read`

See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash
unkey workspace flags get
```

## API endpoint

The command calls `POST /v2/workspace.getFlags` and prints its response. See the <a href="https://github.com/unkeyed/unkey/blob/main/svc/api/openapi/spec/paths/v2/workspace/getFlags/index.yaml" target="_blank">endpoint definition</a> for the HTTP contract. The request has no body.
