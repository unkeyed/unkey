Get the usage of your workspace for one calendar month (UTC): billable API
operations, compute usage per environment, and active keys per app.

Use this to track usage during the month or to look back at a past
month. The response has no prices. Your invoice is the source of truth.
Compute usage can be up to 15 minutes late, and it can change for up to 7
days.

Send `{}` for the current month to date, or
`{"period": {"year": 2026, "month": 9}}` for a full past month. The month
must start within the last 90 days.

Run without `--period` for the current month. Replace the year and month in the example with a month that starts within the last 90 days.

## Usage

```bash
unkey workspace usage [flags]
```

## Flags

<ParamField body="--period" type="string">
  A JSON object. The calendar month (UTC) to read. Omit it for the current month to date. A past month returns the full month. It cannot be in the future, and it must start within the last 90 days, because compute usage is kept for 90 days.

  <Expandable title="Properties">
    <ResponseField name="year" type="integer" required>
      The year, for example 2026.
    </ResponseField>

    <ResponseField name="month" type="integer" required>
      The month, from 1 (January) to 12 (December). Range: 1 to 12.
    </ResponseField>
  </Expandable>
</ParamField>

## Required permissions

Your root key must have this permission:

- `unkey:v1:<workspace_id>:usage#read`

See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash
unkey workspace usage --period='{"year":2026,"month":9}'
```

Send the request body as JSON:

```bash
unkey workspace usage --body='{}'
```

## API endpoint

The command calls `POST /v2/workspace.getUsage` and prints its response. See the <a href="https://github.com/unkeyed/unkey/blob/main/svc/api/openapi/spec/paths/v2/workspace/getUsage/index.yaml" target="_blank">endpoint definition</a> for the HTTP contract. Request fields use camelCase in `--body`.
