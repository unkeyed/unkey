Update a root key in the authenticated workspace.
Requires `unkey:v1:<workspace_id>:rootKeys/<key_id>#write`.
Use `rootKeys/*#write` to update any root key in the workspace.

`permissions` replaces the complete permission set. Each permission must be a supported URN
in the authenticated workspace and within the caller's permissions.
An expiring root key can only update root keys that expire no later than itself.

Provide at least one of `--name`, `--enabled`, or `--permissions`. Omitted fields stay unchanged. An empty `--permissions=` removes all permissions. Use `--body` with `name: null` to remove the name.

## Usage

```bash
unkey root-keys update --key-id=<key-id> [flags]
```

## Flags

<ParamField body="--enabled" type="boolean">
  Whether the root key can authenticate. Omit to keep the current state.
</ParamField>

<ParamField body="--key-id" type="string" required>
  Root key identifier returned by rootKeys.createKey or rootKeys.listKeys.
</ParamField>

<ParamField body="--name" type="string">
  New root key name. Set null to remove the name. Omit to keep the current name. Use `--body` to send `name: null`. An empty string is not a valid name.
</ParamField>

<ParamField body="--permissions" type="string[]">
  Complete replacement permission set. Every permission must be a supported URN in the authenticated workspace and within the caller's permissions. Omit to keep the current permissions. Pass comma-separated permission URNs. Pass `--permissions=` to remove every permission.
</ParamField>

## Examples

```bash
unkey root-keys update --key-id=key_example --enabled=false
```

Send the request body as JSON:

```bash
unkey root-keys update --body='{"keyId":"key_example","name":null,"permissions":[]}'
```

## API endpoint

The command calls `POST /v2/rootKeys.updateKey` and prints its response. See the <a href="https://github.com/unkeyed/unkey/blob/main/svc/api/openapi/spec/paths/v2/rootKeys/updateKey/index.yaml" target="_blank">endpoint definition</a> for the HTTP contract. Request fields use camelCase in `--body`.
