## Add the Unkey server

<Steps titleSize="h3">
  <Step title="Add the server">
    ```bash
    claude mcp add --transport http unkey https://mcp.unkey.com
    ```

    To add the Compute server instead, use its URL:

    ```bash
    claude mcp add --transport http unkey-compute https://mcp.unkey.com/compute
    ```
  </Step>
  <Step title="Sign in">
    Start Claude Code, run `/mcp`, and select the server. Claude Code opens Unkey in your browser. Pick a workspace and permissions, then click **Authorize**. See [Sign in with Unkey](/platform/ai-coding/mcp-servers#sign-in-with-unkey).
  </Step>
  <Step title="Check the connection">
    ```bash
    claude mcp list
    ```

    The server shows **Connected**. Inside a session, run `/mcp` to see its status and tools.
  </Step>
</Steps>

The server is added for you in the current project. Add `--scope user` to use it in every project, or `--scope project` to save it to `.mcp.json` so your team gets it too. Each person then signs in with their own Unkey account.

## Use a root key instead

To connect without a browser sign-in, export a root key and send it as a header. See [Use a root key instead](/platform/ai-coding/mcp-servers#use-a-root-key-instead) for the permissions to give it.

```bash
export UNKEY_ROOT_KEY="unkey_..."
claude mcp add --transport http unkey https://mcp.unkey.com \
  --header 'Authorization: Bearer ${UNKEY_ROOT_KEY}'
```

Keep the single quotes. Claude Code saves `${UNKEY_ROOT_KEY}` as written and reads the variable each time it connects, so the key isn't stored in its config.

## Add the docs

```bash
claude mcp add --transport http unkey-docs "https://www.unkey.com/docs/mcp"
```

Claude Code can then search these docs when you ask about Unkey.
