Each example adds the Unkey server. For the Compute server, swap in `https://mcp.unkey.com/mcp/compute`. In each client you sign in with your Unkey account the first time it connects. See [Sign in with Unkey](/platform/ai-coding/mcp-servers#sign-in-with-unkey). For a machine without a browser, see [Use a root key instead](#use-a-root-key-instead).

## VS Code

Add the server to `.vscode/mcp.json` in your project:

```json
{
  "servers": {
    "unkey": {
      "type": "http",
      "url": "https://mcp.unkey.com/mcp/v2"
    }
  }
}
```

When the server starts, VS Code asks you to allow sign-in and opens Unkey in your browser. To add the docs, open the menu next to **Copy page** on any docs page and choose **Connect to VS Code**.

## Claude Desktop

1. Go to **Settings > Connectors** and choose **Add custom connector**.
2. Name it "Unkey" and paste `https://mcp.unkey.com/mcp/v2` as the URL.
3. Choose **Connect**. Your browser opens Unkey so you can sign in.

## Codex CLI

```bash
codex mcp add unkey --url "https://mcp.unkey.com/mcp/v2"
codex mcp login unkey
```

The second command opens Unkey in your browser. Restart Codex to load the server.

## Any other client

Any client that connects to remote MCP servers over HTTP and supports MCP sign-in works. Give it the server URL. The [install page](https://mcp.unkey.com/mcp/v2/install) also has snippets for opencode and Antigravity.

## Use a root key instead

Send a root key in the `Mcp-Unkey-V2-Bearer` header when the client can't open a browser, such as in CI, or doesn't support MCP sign-in. See [Use a root key instead](/platform/ai-coding/mcp-servers#use-a-root-key-instead) to create one.

### VS Code

```json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "unkey-root-key",
      "description": "Unkey root key",
      "password": true
    }
  ],
  "servers": {
    "unkey": {
      "type": "http",
      "url": "https://mcp.unkey.com/mcp/v2",
      "headers": {
        "Mcp-Unkey-V2-Bearer": "${input:unkey-root-key}"
      }
    }
  }
}
```

VS Code asks for your root key the first time the server starts and stores it for you.

### Claude Desktop

Custom connectors can't send headers, so a root key connects through `mcp-remote`, which needs Node.js.

1. Go to **Settings > Developer > Local MCP Servers > Edit config** to open `claude_desktop_config.json`.
2. Add the server and replace the placeholder with your root key:

```json
{
  "mcpServers": {
    "unkey": {
      "command": "npx",
      "args": [
        "mcp-remote@0.1.25",
        "https://mcp.unkey.com/mcp/v2",
        "--header",
        "Mcp-Unkey-V2-Bearer:${UNKEY_ROOT_KEY}"
      ],
      "env": {
        "UNKEY_ROOT_KEY": "<your root key>"
      }
    }
  }
}
```

3. Save the file and restart Claude Desktop.

### Codex CLI

Codex can't set headers from the command line. After `codex mcp add`, open `~/.codex/config.toml` and add this line to the `[mcp_servers.unkey]` entry, so Codex reads the key from `UNKEY_ROOT_KEY`:

```toml
env_http_headers = { "Mcp-Unkey-V2-Bearer" = "UNKEY_ROOT_KEY" }
```

Restart Codex to load the server.

### Any other client

Give the client the server URL and the `Mcp-Unkey-V2-Bearer` header with your root key.
