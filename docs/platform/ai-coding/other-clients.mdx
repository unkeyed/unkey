Each example adds the Unkey server. For the Compute server, swap in `https://mcp.unkey.com/compute`. After you add the server, the client opens Unkey in your browser so you can sign in. See [Sign in with Unkey](/platform/ai-coding/mcp-servers#sign-in-with-unkey).

## VS Code

Run this command, or use the **Add to VS Code** button on the [install page](https://mcp.unkey.com/install):

```bash
code --add-mcp '{"name":"unkey","type":"http","url":"https://mcp.unkey.com"}'
```

VS Code asks you to sign in to Unkey when the server starts. To add the docs, open the menu next to **Copy page** on any docs page and choose **Connect to VS Code**.

To use a root key instead, add the server to `.vscode/mcp.json` in your project:

```json
{
  "inputs": [
    {
      "type": "promptString",
      "id": "unkey-root-key",
      "description": "Unkey root key",
      "password": true
    }
  ],
  "servers": {
    "unkey": {
      "type": "http",
      "url": "https://mcp.unkey.com",
      "headers": {
        "Authorization": "Bearer ${input:unkey-root-key}"
      }
    }
  }
}
```

VS Code asks for your root key the first time the server starts and stores it for you.

## Claude Desktop

1. Open **Settings**, then **Connectors**, and choose **Add custom connector**.
2. Paste `https://mcp.unkey.com` as the URL.
3. Claude opens Unkey in your browser. Pick a workspace and permissions, then click **Authorize**.

## Codex CLI

```bash
codex mcp add unkey --url https://mcp.unkey.com
codex mcp login unkey
```

The second command opens Unkey in your browser so you can sign in.

To use a root key instead, add the server with `--bearer-token-env-var`. Codex then reads the key from `UNKEY_ROOT_KEY` each time it connects:

```bash
codex mcp add unkey --url https://mcp.unkey.com --bearer-token-env-var UNKEY_ROOT_KEY
```

## Gemini CLI

```bash
gemini mcp add --transport http unkey https://mcp.unkey.com
```

Then run `/mcp auth unkey` in Gemini CLI and sign in to Unkey.

## Windsurf

Add the server to `~/.codeium/windsurf/mcp_config.json`. Windsurf opens the Unkey sign-in when it connects.

```json
{
  "mcpServers": {
    "unkey": {
      "serverUrl": "https://mcp.unkey.com"
    }
  }
}
```

## Any other client

Any client that connects to remote MCP servers over Streamable HTTP and supports MCP's OAuth sign-in works with the server URL alone. If your client can't sign in through a browser, send a root key in the `Authorization: Bearer <root key>` header. See [Use a root key instead](/platform/ai-coding/mcp-servers#use-a-root-key-instead).
