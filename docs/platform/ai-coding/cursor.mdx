## Add the Unkey server

<Steps titleSize="h3">
  <Step title="Edit mcp.json">
    Open `~/.cursor/mcp.json` to use Unkey in every project, or `.cursor/mcp.json` in a project to use it there only. Add the server:

    ```json
    {
      "mcpServers": {
        "unkey": {
          "url": "https://mcp.unkey.com/mcp/v2"
        }
      }
    }
    ```

    For the Compute server, use `https://mcp.unkey.com/mcp/compute` as the URL.
  </Step>
  <Step title="Sign in with Unkey">
    Open **Customize** in the sidebar. Next to **unkey**, choose to connect or log in. Your browser opens Unkey. Pick the workspace and the permissions Cursor gets, then approve. See [Sign in with Unkey](/platform/ai-coding/mcp-servers#sign-in-with-unkey).
  </Step>
  <Step title="Check the connection">
    Check that **unkey** is listed and turned on. Then ask Cursor's agent something like "List my Unkey keyspaces."
  </Step>
</Steps>

If the server doesn't connect, open the Output panel, choose **MCP Logs**, and look for an authentication or connection error.

## Use a root key instead

For a machine without a browser, send a root key in a header instead of signing in. See [Use a root key instead](/platform/ai-coding/mcp-servers#use-a-root-key-instead) to create one. Set `UNKEY_ROOT_KEY` in your shell profile or system environment, restart Cursor so it picks up the variable, and add the header to the server entry:

```json
{
  "mcpServers": {
    "unkey": {
      "url": "https://mcp.unkey.com/mcp/v2",
      "headers": {
        "Mcp-Unkey-V2-Bearer": "${env:UNKEY_ROOT_KEY}"
      }
    }
  }
}
```

## Add the docs

On any docs page, open the menu next to **Copy page** and choose **Connect to Cursor**. Cursor opens and asks you to install the docs MCP server.
