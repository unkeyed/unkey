## Add the Unkey server

<Steps titleSize="h3">
  <Step title="Edit mcp.json">
    Open `~/.cursor/mcp.json` to use Unkey in every project, or `.cursor/mcp.json` in a project to use it there only. Add the server:

    ```json
    {
      "mcpServers": {
        "unkey": {
          "url": "https://mcp.unkey.com"
        }
      }
    }
    ```

    For the Compute server, use `https://mcp.unkey.com/compute` as the URL. The [install page](https://mcp.unkey.com/install) also has an **Add to Cursor** button that writes this entry for you.
  </Step>
  <Step title="Sign in">
    Cursor opens Unkey in your browser when it connects. Pick a workspace and permissions, then click **Authorize**. See [Sign in with Unkey](/platform/ai-coding/mcp-servers#sign-in-with-unkey).
  </Step>
  <Step title="Check the connection">
    Open **Customize** in the sidebar and check that **unkey** is listed and turned on. Then ask Cursor's agent something like "List my Unkey keyspaces."
  </Step>
</Steps>

If the server doesn't connect, open the Output panel, choose **MCP Logs**, and look for an authentication or connection error.

## Use a root key instead

To connect without a browser sign-in, set `UNKEY_ROOT_KEY` in your shell profile or system environment, then restart Cursor so it picks up the variable. Send the key as a header:

```json
{
  "mcpServers": {
    "unkey": {
      "url": "https://mcp.unkey.com",
      "headers": {
        "Authorization": "Bearer ${env:UNKEY_ROOT_KEY}"
      }
    }
  }
}
```

See [Use a root key instead](/platform/ai-coding/mcp-servers#use-a-root-key-instead) for the permissions to give the key.

## Add the docs

On any docs page, open the menu next to **Copy page** and choose **Connect to Cursor**. Cursor opens and asks you to install the docs MCP server.
