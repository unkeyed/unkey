Usage covers one calendar month (UTC), with one total per product: API for every workspace, Compute once you have a Compute plan.

## API management

Usage has two parts, **Key verifications** and **standalone rate limit operations**, metered against your monthly operations quota. Only successful calls count: invalid, expired, or over-limit requests aren't billed. These two are the billable operations that [Limits](/platform/billing/limits) caps and that a paid API tier prices.

### What we meter

| Quantity | How it's billed |
| --- | --- |
| CPU (vCPU-hrs) | Average active virtual CPU per running instance. Billed on actual usage, not the vCPU ceiling you configured. Idle time waiting on I/O does not count as active CPU. |
| Memory (GiB-hrs) | Average memory used per running instance. Billed on actual usage, not the memory ceiling you configured. |
| Storage (GiB-hrs) | Ephemeral disk volume mounted per instance. Billed on the allocated size for as long as the instance runs, up to 10 GiB per instance. |
| Egress (GiB) | Total outbound network data transfer for the month. |
| Verified keys | Distinct keys with at least one verification during the month through a Key Auth policy on Compute. These bill to the project, not a keyspace. |

Runtime settings are ceilings and headroom. Most workloads never pin 100% of CPU or memory, so configuring 1 vCPU while averaging 0.5 vCPU bills the 0.5, not the 1. Preview deployments use the same rates as production.

Unit rates and the plan fee with included usage credit are on [unkey.com/pricing](https://unkey.com/pricing). Use the calculator at the bottom of that page to estimate a month. The plan fee and included credit are also summarized on [Plans](/platform/billing/plans).

Usage is what you consumed. [Limits](/platform/billing/limits) are the ceilings. Costs here are the metered part of the bill.
