List the overrides of a namespace. Results come in pages. Calls `POST /v2/ratelimit.listOverrides`. See [Rate limit overrides](/api-management/ratelimiting/overrides).

## Usage

```bash
unkey ratelimit overrides list --namespace=<namespace> [flags]
```

## Flags

<ParamField body="--namespace" type="string" required>
  Namespace id or name.
</ParamField>

<ParamField body="--cursor" type="string">
  Cursor from the previous response.
</ParamField>

<ParamField body="--limit" type="integer">
  Maximum number of overrides per page, from 1 to 100. Defaults to 50.
</ParamField>

## Required permissions

`ratelimit.*.read_override` or `ratelimit.<namespace_id>.read_override`. See [Root key permissions](/platform/root-keys/permissions).
