Rename a rate limit namespace, identified by its ID or current name.

Renaming to the current name returns the namespace without a write.

Important: Overrides stay with the namespace. Requests that pass the namespace by name, such as `ratelimit.limit`, must use the new name. A `ratelimit.limit` call with the old name can create a new, empty namespace with that name. A name that is in use or was deleted returns 409. Other API nodes can take up to a minute to see the new name.

## Usage

```bash
unkey ratelimit namespaces update --name=<name> --namespace=<namespace> [flags]
```

## Flags

<ParamField body="--name" type="string" required>
  The new name of the namespace, unique within your workspace. Names are case-sensitive.
</ParamField>

<ParamField body="--namespace" type="string" required>
  The namespace to rename. Pass the namespace ID (`rlns_...`) or its current name.
</ParamField>

## Required permissions

Your root key must have one of the following permissions:

- `unkey:v1:<workspace_id>:projects/*/ratelimits/namespaces/*#write` (to rename any namespace)
- `unkey:v1:<workspace_id>:projects/<project_id>/ratelimits/namespaces/<namespace_id>#write` (to rename a specific namespace)

See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash
unkey ratelimit namespaces update --namespace=rlns_1234abcd --name=email.outbound
```

```bash
unkey ratelimit namespaces update --namespace=email.sends --name=email.outbound
```

Send the request body as JSON:

```bash
unkey ratelimit namespaces update --body='{"namespace":"email.sends","name":"email.outbound"}'
```

## API endpoint

The command calls `POST /v2/ratelimit.updateNamespace` and prints its response. See the <a href="https://github.com/unkeyed/unkey/blob/main/svc/api/openapi/spec/paths/v2/ratelimit/updateNamespace/index.yaml" target="_blank">endpoint definition</a> for the HTTP contract. Request fields use camelCase in `--body`.
