Retrieve a paginated list of the rate limit namespaces in your workspace.

Use this to find the namespaces your services rate limit against, for example to build an admin view or to look up a namespace ID. Results are ordered newest first and returned in pages. When `hasMore` is true, pass the returned `cursor` to fetch the next page.

Deleted namespaces are not returned. The list contains only the namespaces your root key can read.

## Usage

```bash
unkey ratelimit namespaces list [flags]
```

## Flags

<ParamField body="--cursor" type="string">
  Pagination cursor from a previous response to fetch the next page. Use when `hasMore: true` in the previous response. Omit this field to start from the first page.
</ParamField>

<ParamField body="--limit" type="integer">
  Maximum number of namespaces to return per request. Omit this field to receive up to 100 namespaces. Range: 1 to 100. The API defaults to 100 when omitted.
</ParamField>

<ParamField body="--search" type="string">
  Free-form text to filter namespaces. Returns namespaces whose ID or name contains the search string. Matching is case-insensitive. Omit this field to list every namespace.
</ParamField>

## Required permissions

Your root key must have one of the following permissions:

- `unkey:v1:<workspace_id>:projects/*/ratelimits/namespaces/*#read` (to read any namespace)
- `unkey:v1:<workspace_id>:projects/<project_id>/ratelimits/namespaces/<namespace_id>#read` (to read a specific namespace)

See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash
unkey ratelimit namespaces list
```

```bash
unkey ratelimit namespaces list --search=email --limit=20
```

```bash
unkey ratelimit namespaces list --cursor=rlns_1234abcd
```

Send the request body as JSON:

```bash
unkey ratelimit namespaces list --body='{"search":"email","limit":20}'
```

## API endpoint

The command calls `POST /v2/ratelimit.listNamespaces` and prints its response. See the <a href="https://github.com/unkeyed/unkey/blob/main/svc/api/openapi/spec/paths/v2/ratelimit/listNamespaces/index.yaml" target="_blank">endpoint definition</a> for the HTTP contract.
