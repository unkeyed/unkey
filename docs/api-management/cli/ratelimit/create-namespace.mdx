Create a rate limit namespace before you rate limit against it.

`ratelimit.limit` also creates a namespace the first time you use its name, when your root key can create namespaces. Use this endpoint when you want the namespace to exist up front, for example to set overrides before the first request.

Important: Names are unique within your workspace, deleted namespaces included. A name that is in use or was deleted returns 409.

## Usage

```bash
unkey ratelimit namespaces create --name=<name> [flags]
```

## Flags

<ParamField body="--name" type="string" required>
  The name of the namespace, unique within your workspace. Names are case-sensitive. Pass it as `namespace` to `ratelimit.limit` and the override endpoints.
</ParamField>

## Required permissions

Your root key must have the following permission:

- `unkey:v1:<workspace_id>:projects/*/ratelimits/namespaces/*#write`

See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash
unkey ratelimit namespaces create --name=email.outbound
```

Send the request body as JSON:

```bash
unkey ratelimit namespaces create --body='{"name":"email.outbound"}'
```

## API endpoint

The command calls `POST /v2/ratelimit.createNamespace` and prints its response. See the <a href="https://github.com/unkeyed/unkey/blob/main/svc/api/openapi/spec/paths/v2/ratelimit/createNamespace/index.yaml" target="_blank">endpoint definition</a> for the HTTP contract. Request fields use camelCase in `--body`.
