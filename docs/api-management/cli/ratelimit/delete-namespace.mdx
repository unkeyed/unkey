Delete a rate limit namespace and all of its overrides, identified by the namespace ID or name.

Important: A deleted name cannot be reused. `ratelimit.limit` and `ratelimit.multiLimit` return 410 for it instead of creating a new namespace, so a deleted namespace does not turn into unlimited traffic. Other API nodes can take up to a minute to see the deletion.

## Usage

```bash
unkey ratelimit namespaces delete --namespace=<namespace> [flags]
```

## Required permissions

Your root key must have one of the following permissions:

- `unkey:v1:<workspace_id>:projects/*/ratelimits/namespaces/*#delete` (to delete any namespace)
- `unkey:v1:<workspace_id>:projects/<project_id>/ratelimits/namespaces/<namespace_id>#delete` (to delete a specific namespace)

See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash
unkey ratelimit namespaces delete --namespace=email.outbound
```

```bash
unkey ratelimit namespaces delete --namespace=rlns_1234abcd --yes
```

Send the request body as JSON without an interactive prompt:

```bash
unkey ratelimit namespaces delete --body='{"namespace":"email.outbound"}' --yes
```

## API endpoint

The command calls `POST /v2/ratelimit.deleteNamespace` and prints its response. See the <a href="https://github.com/unkeyed/unkey/blob/main/svc/api/openapi/spec/paths/v2/ratelimit/deleteNamespace/index.yaml" target="_blank">endpoint definition</a> for the HTTP contract. Request fields use camelCase in `--body`.
