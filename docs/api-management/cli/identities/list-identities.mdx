List identities. Results come in pages. Pass the `cursor` from one response to get the next page. Calls `POST /v2/identities.listIdentities`. See [Identities](/api-management/identities/overview).

## Usage

```bash
unkey identities list [flags]
```

## Flags

<ParamField body="--cursor" type="string">
  Cursor from the previous response.
</ParamField>

<ParamField body="--limit" type="integer">
  Maximum number of identities per page. 1 to 100. Defaults to 100.
</ParamField>

<ParamField body="--search" type="string">
  Return only identities whose id or external id contains this text. Not case-sensitive. Up to 256 characters.
</ParamField>

## Required permissions

`identity.*.read_identity`. A root key with only `identity.<identityId>.read_identity` fails as soon as the page includes any other identity. See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash First page
unkey identities list --limit=50
```

```bash Search
unkey identities list --search=user_123
```

Or send the whole request as JSON:

```bash Raw body
unkey identities list --body='{"limit":50,"search":"user_"}'
```
