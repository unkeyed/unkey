Update an identity. `--meta` and `--ratelimits` each replace the whole existing value, so pass everything you want to keep. Changes can take up to about 10 seconds to reach verifications. Calls `POST /v2/identities.updateIdentity`. See [Identities](/api-management/identities/overview).

## Usage

```bash
unkey identities update --identity=<identity> [flags]
```

## Flags

<ParamField body="--identity" type="string" required>
  Identity id or external id.
</ParamField>

<ParamField body="--meta" type="string">
  JSON object that replaces the identity's metadata.
</ParamField>

<ParamField body="--ratelimits" type="string">
  JSON array that replaces the identity's rate limits.
</ParamField>

## Required permissions

`identity.*.update_identity`. Without the permission you get a 404, so the response doesn't reveal whether the identity exists. If your key can read the identity, you get a 403 that names the missing permission instead. See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash Replace metadata
unkey identities update --identity=user_123 --meta='{"plan":"enterprise"}'
```

Or send the whole request as JSON:

```bash Raw body
unkey identities update --body='{"identity":"user_123","ratelimits":[{"name":"requests","limit":5000,"duration":3600000,"autoApply":true}]}'
```
