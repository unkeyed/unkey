Create an identity. Keys linked to it by `externalId` share its metadata and rate limits, so a user with several keys is rate limited as one. Calls `POST /v2/identities.createIdentity`. See [Identities](/api-management/identities/overview).

## Usage

```bash
unkey identities create --external-id=<external id> [flags]
```

## Flags

<ParamField body="--external-id" type="string" required>
  Your identifier for the user, organization, or tenant. Unique per workspace. Reusing one returns 409 [`err:unkey:data:identity_already_exists`](/errors/unkey/data/identity_already_exists).
</ParamField>

<ParamField body="--meta" type="string">
  JSON object stored on the identity and returned when any of its keys is verified.
</ParamField>

<ParamField body="--ratelimits" type="string">
  JSON array of rate limits shared by every key of the identity, each with `name`, `limit`, `duration` in milliseconds, and `autoApply`.
</ParamField>

## Required permissions

`identity.*.create_identity`. See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash Create
unkey identities create --external-id=user_123
```

```bash Create with a shared rate limit
unkey identities create --external-id=user_123 --ratelimits='[{"name":"requests","limit":1000,"duration":3600000,"autoApply":true}]'
```

Or send the whole request as JSON:

```bash Raw body
unkey identities create --body='{"externalId":"user_123","meta":{"plan":"pro"}}'
```
