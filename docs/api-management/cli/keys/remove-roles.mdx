Remove roles from a key. Direct permissions and other roles stay. Changes can take up to about 10 seconds to apply. Calls `POST /v2/keys.removeRoles`. See [Managing key permissions](/api-management/authorization/managing-key-permissions).

## Usage

```bash
unkey keys roles remove --key-id=<key id> --roles=<roles> [flags]
```

## Flags

<ParamField body="--yes" type="boolean">
  <CLIConfirmation />
</ParamField>

<ParamField body="--key-id" type="string" required>
  Id of the key.
</ParamField>

<ParamField body="--roles" type="string[]" required>
  Comma-separated role names to remove. An unknown name fails the call instead of being ignored.
</ParamField>

## Required permissions

`api.*.update_key` or `api.<apiId>.update_key` for the API the key belongs to. See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash Remove a role
unkey keys roles remove --key-id=key_1234abcd --roles=billing_reader
```

Or send the whole request as JSON:

```bash Raw body
unkey keys roles remove --body='{"keyId":"key_1234abcd","roles":["billing_reader"]}'
```
