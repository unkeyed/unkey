Delete a key. By default we keep a record of the deleted key for audit logs and analytics, but you can't restore it. `--permanent` erases the key completely, including its metadata. The key can keep verifying for up to about 10 seconds. Calls `POST /v2/keys.deleteKey`. See [Enabling, disabling, and deleting keys](/api-management/keys/enable-disable-delete).

## Usage

```bash
unkey keys delete --key-id=<key id> [flags]
```

## Flags

<ParamField body="--yes" type="boolean">
  <CLIConfirmation />
</ParamField>

<ParamField body="--key-id" type="string" required>
  Id of the key to delete.
</ParamField>

<ParamField body="--permanent" type="boolean" default="false">
  Erase the key completely instead of keeping a record. Use it for compliance deletions or to reuse a key string. Analytics rows for the key lose their link to it.
</ParamField>

## Required permissions

`api.*.delete_key` or `api.<apiId>.delete_key`. See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash Soft delete
unkey keys delete --key-id=key_1234abcd
```

```bash Permanent delete
unkey keys delete --key-id=key_1234abcd --permanent
```

Or send the whole request as JSON:

```bash Raw body
unkey keys delete --body='{"keyId":"key_1234abcd","permanent":true}'
```
