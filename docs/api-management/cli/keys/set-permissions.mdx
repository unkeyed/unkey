Replace all direct permissions on a key in one step. Permissions not in the list are removed, and roles are untouched. Changes can take up to about 10 seconds to apply. Calls `POST /v2/keys.setPermissions`. See [Managing key permissions](/api-management/authorization/managing-key-permissions).

## Usage

```bash
unkey keys permissions set --key-id=<key id> --permissions=<permissions> [flags]
```

## Flags

<ParamField body="--key-id" type="string" required>
  Id of the key.
</ParamField>

<ParamField body="--permissions" type="string[]" required>
  Comma-separated permission slugs that become the key's full set of direct permissions. A slug that doesn't exist yet is created.
</ParamField>

## Required permissions

`api.*.update_key` or `api.<apiId>.update_key` together with `rbac.*.add_permission_to_key` and `rbac.*.remove_permission_from_key`. Creating a new slug also needs `rbac.*.create_permission`. See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash Set the exact permissions
unkey keys permissions set --key-id=key_1234abcd --permissions=documents.read,documents.write,settings.view
```

Or send the whole request as JSON:

```bash Raw body
unkey keys permissions set --body='{"keyId":"key_1234abcd","permissions":["documents.read","settings.view"]}'
```
