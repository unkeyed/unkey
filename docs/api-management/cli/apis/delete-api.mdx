Delete a keyspace. Every key in it stops verifying within about 10 seconds, so treat this as irreversible. If delete protection is on, the call fails with [`err:unkey:application:protected_resource`](/errors/unkey/application/protected_resource). You can only turn delete protection off in the dashboard. Calls `POST /v2/apis.deleteApi`. See [Keyspaces](/api-management/keyspaces/overview).

## Usage

```bash
unkey apis delete --api-id=<api id> [flags]
```

## Required permissions

`api.*.delete_api` or `api.<apiId>.delete_api`. See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash Delete an API
unkey apis delete --api-id=api_1234abcd
```

Or send the whole request as JSON:

```bash Raw body
unkey apis delete --body='{"apiId":"api_1234abcd"}'
```
