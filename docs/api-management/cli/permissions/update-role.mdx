Update the name or description of a role, identified by its ID or name.

Omitted fields keep their current values. A request with no fields to update returns the stored role without a write.

This endpoint does not change the role's permissions or keys. Use `permissions.setRolePermissions`, `keys.addRoles`, and `keys.removeRoles` for those.

Important: Keys keep the role after a rename. Requests that name the role, such as `keys.addRoles`, must use the new name. Key verification can return the old name for a short time while caches refresh. A name that another role in your workspace already uses returns 409.

## Usage

```bash
unkey roles update --role=<role> [flags]
```

## Flags

<ParamField body="--description" type="string">
  New description for the role. Omit this field to keep the current description. Send null or an empty string to remove it. Pass `--description=` to remove it, or use `--body` with `description: null`.
</ParamField>

<ParamField body="--name" type="string">
  New name for the role. The name must be unique in your workspace. Omit this field to keep the current name.
</ParamField>

<ParamField body="--role" type="string" required>
  The role to update. Pass the role ID (`role_...`) or its current name.
</ParamField>

## Required permissions

Your root key must have the following permission:

- `unkey:v1:<workspace_id>:projects/<project_id>/rbac/roles/<role_id>#write`

See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash
unkey roles update --role=role_1234abcd --name=support.readonly
```

```bash
unkey roles update --role=support.readonly --description=
```

Send the request body as JSON:

```bash
unkey roles update --body='{"role":"support.readonly","description":null}'
```

## API endpoint

The command calls `POST /v2/permissions.updateRole` and prints its response. See the <a href="https://github.com/unkeyed/unkey/blob/main/svc/api/openapi/spec/paths/v2/permissions/updateRole/index.yaml" target="_blank">endpoint definition</a> for the HTTP contract. Request fields use camelCase in `--body`.
