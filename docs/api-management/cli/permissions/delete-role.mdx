<RootKeyPrereq />

Delete a role. Keys that had it lose its permissions within about 10 seconds. The permissions themselves aren't deleted. Calls `POST /v2/permissions.deleteRole`. See [Roles and permissions](/api-management/authorization/roles-and-permissions).

## Usage

```bash
unkey roles delete --role=<role> [flags]
```

## Required permissions

`rbac.*.delete_role`. Without the permission you get a 404, so the response doesn't reveal whether the resource exists. If your key can read the role, you get a 403 that names the missing permission instead. See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash Delete
unkey roles delete --role=api_reader
```

Or send the whole request as JSON:

