Replace a role's permissions. An empty set removes them all. Keys with the role pick up the change within about 10 seconds. Calls `POST /v2/permissions.setRolePermissions`. See [Roles and permissions](/api-management/authorization/roles-and-permissions).

## Usage

```bash
unkey roles permissions set (--role=<role> | --role-id=<id>) --permissions=<slugs> [flags]
```

## Flags

<ParamField body="--role" type="string">
  Role id or name. Pass this or `--role-id`.
</ParamField>

<ParamField body="--role-id" type="string">
  Old name for `--role`, kept so existing scripts work. Use `--role`.
</ParamField>

<ParamField body="--permissions" type="string[]">
  Comma-separated permission slugs that become the role's full set. Slugs that don't exist yet are created. Pass an empty value to remove all. Required unless you use `--body`.
</ParamField>

## Required permissions

`rbac.*.add_permission_to_role` and `rbac.*.remove_permission_from_role`. Creating new slugs also needs `rbac.*.create_permission`. See [Root key permissions](/platform/root-keys/permissions).

## Examples

```bash Set
unkey roles permissions set --role=role_1234abcd --permissions=documents.read,documents.write
```

```bash Clear
unkey roles permissions set --role=role_1234abcd --permissions=
```

Or send the whole request as JSON:

```bash Raw body
unkey roles permissions set --body='{"role":"role_1234abcd","permissions":["documents.read"]}'
```
