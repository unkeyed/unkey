This index lists every service under `svc/`. Each documented service follows
the structure defined in
[Documenting services](/contributing/quality/documenting-services): an
overview, a generated configuration reference, and an operations page.

| Service | Purpose | Code | Docs |
| --- | --- | --- | --- |
| API | Public HTTP API for key management, verification, and analytics | `svc/api` | [Overview](/architecture/services/api/overview) |
| Control plane | Deployment control plane: RPC API plus a Restate worker for deploy workflows | `svc/ctrl` | [API](/architecture/services/control-plane/api/overview), [Worker](/architecture/services/control-plane/worker/overview) |
| Frontline | Multi-tenant ingress and gateway: TLS termination, policy enforcement, routing | `svc/frontline` | [Overview](/architecture/services/frontline/overview) |
| Heimdall | Per-node resource metering agent; writes container counter checkpoints to ClickHouse | `svc/heimdall` | Not written yet |
| Krane | Node-level orchestration agent that manages deployments on Kubernetes | `svc/krane` | [Overview](/architecture/services/krane/overview) |
| Logdrain | Streams audit logs from ClickHouse to customer destinations | `svc/logdrain` | [Overview](/architecture/services/logdrain/overview) |
| Vault | Encrypts and decrypts secrets for the other services | `svc/vault` | [Overview](/architecture/services/vault/overview) |
