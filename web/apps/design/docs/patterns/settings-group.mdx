## Settings forms

`SettingsGroups` stacks the groups of a settings page. Each `SettingsGroupContent` draws one card and collects the `SettingsForm` rows inside it. The card shows one Save button for all of its rows, and saves only the rows with changes.

- One `SettingsForm` can hold more than one row. It spaces its rows the same as the card or panel around it, so do not add divider or gap classes.
- `pendingNote` on `SettingsGroups` shows beside Save while a card has unsaved changes. Use it to say when the change takes effect.
- A card reports its unsaved changes to the nearest unsaved-changes scope. See [Slide panel](/primitives/slide-panel#unsaved-changes-registry).

## Collapsible group

<Component path="settings-group/collapsible" />

Use `SettingsGroupCollapsible` for settings that most users keep at the default. The closed header shows `summary`, or "Unsaved changes" while a row in the card is dirty.

## Save in a slide panel

<Component path="settings-group/panel" />

`SettingsPanel` puts settings forms in a slide panel with Cancel and one Save in the footer. Save saves every changed form. `onSaved` runs when every one of those saves succeeds. Each label sits above a full-width control, with the description under it.
