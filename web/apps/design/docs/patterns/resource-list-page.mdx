## Structure

Put the resource name and primary creation action in `PageHeader`. Put search, filters, and sorting in `ResourceListHeader`, in this order from left to right: search, filters, then the view toggle on the right edge. Show 18 items first. If more results are available, put `ResourceListShowMore` in `ResourceListFooter`. Do not add a result count.

A list that offers both cards and rows uses `ResourceListViewToggle`. Both views show the same items and the same Show more footer.
