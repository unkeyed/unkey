Use a secondary navigation when pages have sections nested one level deep within them.

<Component path="layout/secondary-nav" />

## Back link

Detail pages put a `PageHeaderBack` link above the title. It points to the parent list.

<Component path="layout/back" />

In the dashboard, pass a Next.js link with `render={<Link href={listHref} />}` so the navigation stays client-side.

## Full width

For full width pages like logs, requests, use the full width prop to let your page span the entire width of the viewport.
