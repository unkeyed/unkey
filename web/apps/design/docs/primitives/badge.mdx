title: Badge
description: A small label for a status, a count or a code value.

<Component path="badge/variants" />

## Variants

- `primary`, `secondary`: neutral labels.
- `success`, `warning`, `error`: status. Pick by the state, not by the color you want.
- `blocked`: status for a refused request, for example a disabled or expired key. A deployment that waits for approval uses `warning`.
- `count`: a number next to a tab or a heading.
- `code`: a slug, an ID or a branch name in running text. It truncates to its container and keeps the line height of the text around it.

## Sizes

<Component path="badge/sizes" />

- Default: 22px high.
- `sm`: 22px high, with tighter horizontal padding.
- `compact`: 20px high. Use it for a status dot or an icon and a label inside a dense header row. It adds a gap between the dot and the label.
