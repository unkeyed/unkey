## Variants

- `default`: a segmented control on a gray track. Use it for a small switch inside a card or a panel.
- `underline`: a full-width row with a line under the active tab. Use it for page sections, such as the Traffic, Resources and Instances tabs on the metrics page.

Set the variant on `TabsList`. Each `TabsTrigger` reads it from the list, so do not set it on the triggers.
