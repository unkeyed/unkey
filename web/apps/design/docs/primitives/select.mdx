## Sizes

- `md` is the default. Use it in forms.
- `sm` fits dense rows, toolbars and slide panels. It is 32px tall with a smaller chevron.

Set the size on `SelectTrigger`. `SelectContent` already sits above slide panels and dialogs, so do not add a `z-*` class to it.
