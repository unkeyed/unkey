## Sizes

- `md` is the default. Use it in forms.
- `sm` fits dense rows, toolbars and slide panels. It is 32px tall with a smaller chevron.

Set the size on `SelectTrigger`. `SelectContent` already sits above slide panels and dialogs, so do not add a `z-*` class to it.

## Long lists

Pass `maxRows` to `SelectContent` when the list is long or sits above other fields. The list stops at that many rows and scrolls. Use 5 in forms and slide panels.

## FormSelect

`FormSelect` wraps the four Select parts with a label, a description and an error. Use it before you build a Select by hand.

<Component path="select/form-select-inline" />

- Without `label`, give it an `aria-label`. It then fits inline in a row.
- `size="sm"` uses the small trigger.
- `multiple` takes and returns an array of values.
- The value type follows the options, so `onValueChange` needs no narrowing.
