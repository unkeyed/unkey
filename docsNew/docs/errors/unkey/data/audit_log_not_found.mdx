:::danger
`err:unkey:data:audit_log_not_found`
:::

This code is reserved, and the API doesn't return it. No endpoint looks up a single audit log entry.

## How to fix

There's nothing to fix. You read audit logs in the dashboard. Entries are dropped once they're older than your plan's retention. See [Limits](/platform/billing/limits).
