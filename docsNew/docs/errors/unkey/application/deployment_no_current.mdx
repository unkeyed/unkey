:::danger
`err:unkey:application:deployment_no_current`
:::

The app has no current deployment yet, so there's nothing to promote over or roll back from. You get HTTP 412.


```json Example response
{
  "meta": {
    "requestId": "req_2c9a0jf23l4k567"
  },
  "error": {
    "detail": "The app has no current deployment.",
    "status": 412,
    "title": "Precondition Failed",
    "type": "/errors/unkey/application/deployment_no_current"
  }
}
```

## Likely causes

- No production deployment for this app has succeeded yet. The first one that succeeds becomes current on its own.

## How to fix

1. Create a production deployment with `deployments.createDeployment` and let it finish. It becomes current on its own.
2. Use promote and rollback later, to move between deployments that already exist.

## Related errors

- [`err:unkey:application:deployment_is_current`](/errors/unkey/application/deployment_is_current): the target is already the current deployment.
- [`err:unkey:application:deployment_not_ready`](/errors/unkey/application/deployment_not_ready): the target isn't ready.
