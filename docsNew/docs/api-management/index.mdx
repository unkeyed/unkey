Use API Management to issue API keys for a public API and to verify them on each request. Call `keys.createKey` to issue a key, and call `keys.verifyKey` from your backend to check it. Your app can stay on the host you already use. Compute is the other product, and you don't need it for this.

Unkey stores only a hash of each key. Verification runs the checks you configure (expiry, credits, rate limits, permissions, IP allow lists) and returns one verdict. If you already have keys, [Migrating keys](/api-management/keys/migrating-keys) explains how to import their hashes.

## How this ties to Compute and Platform

Root keys authenticate your calls to the Unkey API, and both products share the CLI. You'll find both documented in [Platform](/platform). If you also host your app on Unkey, the Compute gateway can verify keys for you with its key-auth policy. See [API key authentication](/compute/gateway/api-key-auth).
