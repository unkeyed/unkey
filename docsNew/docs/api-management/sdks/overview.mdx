Use an SDK to call the Unkey API from your code. We publish clients for TypeScript, Go, and Python that cover every endpoint, plus smaller TypeScript packages for one job each, such as verifying keys in a Hono route. The community maintains a Nuxt module. Every package that calls the API needs a root key.

## Packages

| Package | Language | Current version | What it is |
| --- | --- | --- | --- |
| [@unkey/api](/api-management/sdks/typescript/api) | TypeScript | {{tsApi}} | Generated client for the whole API |
| [@unkey/ratelimit](/api-management/sdks/typescript/ratelimit) | TypeScript | {{tsRatelimit}} | Standalone rate limiting with timeouts and fallbacks |
| [@unkey/hono](/api-management/sdks/typescript/hono) | TypeScript | {{tsHono}} | Hono middleware that verifies the bearer key |
| [@unkey/nextjs](/api-management/sdks/typescript/nextjs) | TypeScript | {{tsNextjs}} | `withUnkey` wrapper for Next.js route handlers |
| [@unkey/cache](/api-management/sdks/typescript/cache) | TypeScript | {{tsCache}} | Typed tiered cache with stale-while-revalidate |
| [Go SDK](/api-management/sdks/go) | Go | {{goSdk}} | Generated client, module `github.com/unkeyed/sdks/api/go/v3` |
| [Python SDK](/api-management/sdks/python) | Python | {{pySdk}} | Generated client `unkey.py`, sync and async |
| [Nuxt module](/api-management/sdks/community/nuxt) | TypeScript | {{tsNuxt}} | Community-maintained Nuxt integration |

The TypeScript, Go, and Python clients match the [API reference](/api-management/api-reference/keys/verify-api-key), so method names and fields line up across languages. The Python client ({{pySdk}}) covers API Management only. The TypeScript and Go clients also cover Compute.

## Which package to use

- **`@unkey/api`, the Go SDK, or the Python SDK** when you call several endpoints or want full types.
- **`@unkey/hono` or `@unkey/nextjs`** when you only need to check incoming requests for a valid key. They call `keys.verifyKey` and give your handler the result.
- **`@unkey/ratelimit`** to rate limit user IDs or IP addresses without issuing keys. It adds a timeout and fallback so a network problem can't block your function.
- **`@unkey/cache`** for typed caching in your own services. It doesn't call the Unkey API.

## One client, both products

The TypeScript and Go clients cover Compute too, so the same `Unkey` instance that <Tooltip tip="Here: checking an API key on a request with keys.verifyKey. Not domain verification.">verifies</Tooltip> a key can create a deployment for a Compute <Tooltip tip="A Compute app: a deployable service inside a project. Not 'your application' in general.">app</Tooltip>. The [Go SDK](/api-management/sdks/go) page shows the same pair in Go. From Python, call Compute endpoints over HTTP. The endpoints are [keys.verifyKey](/api-management/api-reference/keys/verify-api-key) and [deployments.createDeploymentV3](/compute/api-reference/deployments/create-deployment).

<CodeGroup>


```typescript Verify a key
import { Unkey } from "@unkey/api";

const unkey = new Unkey({ rootKey: process.env.UNKEY_ROOT_KEY ?? "" });

const result = await unkey.keys.verifyKey({ key: "prod_abc123" });

if (!result.data.valid) {
  // result.data.code says why: NOT_FOUND, DISABLED, EXPIRED, RATE_LIMITED, ...
}
```


```typescript Create a deployment
import { Unkey } from "@unkey/api";

const unkey = new Unkey({ rootKey: process.env.UNKEY_ROOT_KEY ?? "" });

const result = await unkey.deployments.createDeploymentV3({
  project: "my-project",
  app: "api",
  environment: "production",
  oci: { image: "ghcr.io/acme/api:v1.0.0" },
});

console.log(result.data.deploymentId);
```

</CodeGroup>

For Compute concepts such as projects, apps, and <Tooltip tip="A production or preview environment of a Compute app, not the dashboard label on a key.">environments</Tooltip>, see [Projects, apps, and environments](/compute/concepts/projects-apps-environments).

## Response shape

Every successful response has `meta.requestId` (quote it when you contact support) and `data`, the result. Errors are thrown or returned as typed errors per HTTP status. Each SDK page shows how to catch them. See [API overview](/platform/api/overview) for the raw format.
